# Week 1 Quiz Answer Key

## Lesson 1: LLMs vs Agents
1. What is the cleanest difference between an LLM and an agent?
   Answer: A. An LLM answers, an agent can act with tools
2. Which one is an LLM?
   Answer: C. Claude
3. Which example fits an agent best?
   Answer: B. Search Drive, find a file, update a project, and report proof

## Lesson 2: Claude Setup and First Prompt
1. What is Claude best used for in this course?
   Answer: D. Thinking, writing, planning, and explaining
2. What should you avoid pasting into Claude?
   Answer: B. Secrets or private client data
3. What makes a first prompt useful?
   Answer: A. Context, goal, constraints, and desired output

## Lesson 3: Codex Setup and When to Use It
1. When should Reagan use Codex?
   Answer: C. For building, editing, reviewing, or checking work
2. Why compare Claude and Codex?
   Answer: D. Different tools catch different things
3. Who makes the final call?
   Answer: A. Reagan

## Lesson 4: Set Up Your Telegram Agent
1. What is Telegram in this setup?
   Answer: B. The front door where Reagan talks to the agent
2. Which command starts the Codex subscription login flow?
   Answer: D. hermes login --provider openai-codex
3. Where should bot tokens be saved?
   Answer: C. A private local secret location, never the workbook or screenshots
4. Which command helps Reagan find saved sessions later?
   Answer: B. hermes sessions list

## Lesson 5: Markdown, Saved Work, and Agent Orgs
1. What is Markdown best for here?
   Answer: A. Saving structured instructions and proof
2. What is an orchestrator?
   Answer: D. The role that routes work to the right specialist
3. Why make an agent org chart?
   Answer: C. To give each agent a clear lane and proof standard
4. What should help Reagan log back in later?
   Answer: A. A saved folder, MD files, session notes, and proof log

## Lesson 6: Skills, Commands, Tools, and MCPs
1. Are skills and commands tied to one app only?
   Answer: B. No, similar ideas can exist across multiple agent systems
2. What is an MCP?
   Answer: C. A standard connection that lets an agent use outside tools or data
3. What should Reagan ask when a term appears in a new app?
   Answer: D. What app am I using, and what does this word mean here?

## Lesson 7: First Project, My AI Workspace
1. What is the Week 1 project?
   Answer: B. Set up and document my AI workspace
2. What must Reagan be able to do later?
   Answer: C. Log back in, find saved work, and resume
3. What makes the project complete?
