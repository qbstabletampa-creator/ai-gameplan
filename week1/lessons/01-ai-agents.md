# Lesson 1.1: LLMs vs AI Agents

## Goal

Reagan can explain the difference between a chatbot, an LLM, and an AI agent in normal language.

## Plain English

An LLM predicts and writes language.

A chatbot answers inside a conversation.

An AI agent can work through a task. It can read files, use tools, write code, search, remember context, and keep going until the job is done.

## Sports example

A chatbot can answer:

"What should a game day checklist include?"

An agent can:

1. Read last week's checklist.
2. Compare it to this week's schedule.
3. Build a new checklist.
4. Save it in the right folder.
5. Text the staff if something is missing.

That is the difference.
