# Lesson 1.3: Claude Code Setup and First Task

## Goal

Reagan can open a project in Claude Code, ask it to inspect the files, and make one useful change.

## Setup target

Claude Code is your coding teammate. It can read the repo, suggest changes, edit files, and explain what it did.

## Watch

Use `week1/video-resources.md`, section 3.

## First task

Create a repo called:

```text
reagan-ai-workbench
```

Add a README with:

- who you are
- what this internship is
- what you want to learn
- what project you might build

Ask Claude Code:

```text
Read this repo and improve the README so it sounds clear, professional, and still like me.
Do not make it sound corporate.
Explain every change before you make it.
```

## Save proof

Take a screenshot of:

- Claude Code working in the repo
- the final README
- `git status`

## Done looks like

The README is better, and Reagan can explain what Claude Code changed.
