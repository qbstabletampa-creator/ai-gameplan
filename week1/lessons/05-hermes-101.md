# Lesson 1.5: Hermes 101

## Goal

Reagan understands what Hermes is and how CJ uses agents to run real work.

## Plain English

Hermes is CJ's agent system.

It is not just a chatbot. It can use skills, tools, memory, Mission Control, Drive, texting, email, and project workflows.

## What Reagan should understand

- **Tools** are actions Hermes can take.
- **Skills** are saved playbooks for how to do a job right.
- **Memory** is stable context that matters later.
- **Mission Control** is the project board.
- **Drive** is where business files live.
- **Agents** can be given work and report back.

## CJ demo

CJ or Hermes shows:

1. Pull Mission Control.
2. Search Drive.
3. Load a skill.
4. Update a project.
5. Explain the difference between memory and a skill.

## Do

Write a one page reflection:

- What does Hermes do?
- How is it different from ChatGPT?
- What is one safe way Reagan could use a system like this in a college athletics office?
- What should an agent never do without approval?

## Done looks like

Reagan can explain Hermes without using tech buzzwords.
