# Lesson 1.4: Codex Setup and First Task

## Goal

Reagan can use Codex on the same repo and compare it to Claude Code.

## Watch

Use `week1/video-resources.md`, section 4.

## First task

Ask Codex to create a simple file:

```text
projects/project-ideas.md
```

Prompt:

```text
Create 10 project ideas for my summer internship.
They should connect AI tools to college athletics, sports operations, recruiting, content, or job research.
Keep each idea practical and realistic for a beginner.
```

Then ask Codex:

```text
Pick the strongest 3 ideas and explain why.
```

## Compare

Write 5 bullets:

- What Claude Code did well
- What Codex did well
- Which one felt easier
- Which one gave better explanations
- Which one you would use for your final project and why

## Done looks like

Reagan has used both tools and can explain the difference from experience.
