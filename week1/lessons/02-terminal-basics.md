# Lesson 1.2: Terminal Basics

## Goal

Reagan can move around folders, list files, create folders, and run simple commands.

## Commands to learn

```bash
pwd
ls
cd
mkdir
touch
open .
code .
git status
```

## What each one means

- `pwd` tells you where you are.
- `ls` shows what is in the folder.
- `cd` moves you into another folder.
- `mkdir` creates a folder.
- `touch` creates a file.
- `open .` opens the current folder on Mac.
- `code .` opens the current folder in VS Code.
- `git status` shows what changed in your repo.
