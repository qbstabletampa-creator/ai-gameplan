# Lesson 1.6: GitHub Basics

## Goal

Reagan can save work in GitHub and show proof that she built something.

## Words to know

- **Repo:** project folder in GitHub.
- **Commit:** saved checkpoint.
- **Push:** send local changes to GitHub.
- **README:** the front page of the project.
- **Issue:** a task or problem to track.
