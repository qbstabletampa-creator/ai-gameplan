# Week 1: Build Your AI Workbench

Built for Reagan.

This week is not about memorizing tools. It is about learning how to work with AI agents, save your work, explain your thinking, and build something useful.

## Week 1 outcome

By Friday, Reagan can:

1. Explain the difference between a chatbot, an LLM, and an AI agent.
2. Use the terminal without panic.
3. Use Claude Code on a real project folder.
4. Use Codex on a real project folder.
5. Understand what Hermes does inside CJ's system.
6. Create a GitHub repo and save work the right way.
7. Present one working project choice:
   - Sports Ops Assistant
   - Job Researcher

## Required tools

- Laptop
- GitHub account
- Claude Code access
- Codex access
- Hermes demo access through CJ
- Google Drive folder for clean docs

## Daily rhythm

- Watch with purpose.
- Build something small.
- Write what you learned.
- Save it to GitHub.
- Ask if stuck longer than 30 minutes.

## Friday deliverables

1. Written explanation: LLM vs AI agent.
2. Terminal command cheat sheet, in Reagan's own words.
3. Claude Code task completed.
4. Codex task completed.
5. Hermes 101 reflection.
6. GitHub repo with README.
7. Final project demo.
8. Friday check in form.

## Folder guide

- `lessons/` has the teaching material.
- `assignments/` has what Reagan completes.
- `templates/` has starter files she can copy.
- `rubrics/` has the Friday grading sheet.
- `coach-notes/` has CJ's review guide.
