# Week 1 Final Project Brief

Choose one.

## Path 1: Sports Ops Assistant

Build a plan for an AI assistant that helps a college athletics office run smoother.

### Required sections

1. Name of assistant
2. Who it helps
3. Problem it solves
4. 5 tasks it can do
5. 10 starter prompts
6. Safety rules
7. What you would build in version 2

### Starter prompt

```text
You are helping me design a beginner AI assistant for college athletics operations.
Make it practical. No hype.
Focus on tasks an intern or operations assistant would actually do.
```

## Path 2: Job Researcher

Build a plan for an AI assistant that helps Reagan find and apply for college athletics jobs.

### Required sections

1. Name of assistant
2. Job types it searches for
3. 10 target organizations
4. Research fields for each organization
5. Outreach message template
6. Application tracker fields
7. Weekly workflow

### Starter prompt

```text
You are helping me design a job researcher for college athletics roles.
Focus on entry level, internship, operations, recruiting, social media, and athletic department roles.
Give me a realistic system I can use every week.
```
